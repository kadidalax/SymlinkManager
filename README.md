# Windows 软链接管理器

用于在 Windows 上创建、检查和删除符号链接与目录联接的图形界面工具。

## 最重要的概念：Source 和 Target

界面统一使用 `Source` / `Target` 两个字段，并明确标注含义，避免和 `mklink` 的参数顺序搞反：

| 字段 | 含义 | 例子 |
|---|---|---|
| **Source（源）** | **已经存在**的真实文件/文件夹，数据实际存放的位置 | `D:\Data\Project` |
| **Target（目标）** | **要新建**的链接路径，最后一段就是链接名称，**不能已存在** | `C:\Links\Project` |

方向：

```text
Source（真实数据）  ──►  Target（新链接）
D:\Data\Project           C:\Links\Project
```

双击 `C:\Links\Project` 就会打开 `D:\Data\Project`；删除链接不会删除 `D:\Data\Project` 里的任何内容。

> 注意：Target 要填**完整的新路径**。添加窗口里的「浏览」只能选父文件夹，链接名称需要自己输入；不要直接选一个已存在的文件夹。

## 使用方法

1. 把 `SymlinkManager.ps1`、`start.bat` 放在同一个文件夹。
2. 双击 `start.bat`。
3. 需要创建**符号链接**时，点界面下方的「以管理员身份重启」；只创建 **Junction** 不需要管理员。

也可以直接运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\SymlinkManager.ps1
```

要求 Windows 7 SP1 或更高版本，**PowerShell 5.0+**。`-ItemType SymbolicLink` 从 PowerShell 5.0 开始提供。

## 链接类型怎么选

| 类型 | 管理员 | 能链接什么 | 说明 |
|---|---|---|---|
| **目录联接 Junction** | 不需要 | 本地文件夹 | 兼容性最好，推荐默认使用 |
| **目录符号链接** | 通常需要 | 文件夹、网络路径 | 可跨盘、可指向 UNC |
| **文件符号链接** | 通常需要 | 文件 | 用于单个文件 |

默认「自动」：文件夹用 Junction，文件用符号链接；如果文件夹在网络上则用符号链接。

## 主要特性

- **Source / Target 方向清晰**：主界面、添加窗口、使用说明都标注含义和示例。
- **安全创建**：Target 已存在时直接报错，不覆盖同名文件/文件夹。
- **创建前校验**：Source 是否存在、Target 父目录是否存在、名称是否合法、路径是否过长、磁盘是否 NTFS/ReFS、是否网络共享/同步盘、是否存在循环链接。
- **安全删除**：只删除符号链接/目录联接（校验 `LinkType`），拒绝普通文件夹、云占位符和其他重解析点；不使用递归删除，避免跟随链接误删目标内容。
- **配置容错**：`symlinks.json` 损坏时自动备份并从空列表启动；兼容旧格式字段。
- **状态校验**：显示「正常 / 目标失效 / 链接不存在 / 不是链接 / 记录不一致」，会沿嵌套链接链检查最终目标；异常行标色，鼠标悬停看详情。
- **网络路径支持**：正确处理 UNC 路径，网络 Source 的状态校验和双击打开正常。
- **快捷操作**：双击表格行打开链接；支持右键菜单、回车打开、Delete 删除。
- **界面信息**：管理员状态提示、配置路径显示，面板随窗口调整。
- **帮助界面**：使用说明按「快速上手 / 创建链接 / 链接类型 / 注意事项」分标签页，重点用标题、项目符号和示例块区分。
- **日志**：出错时写入 `symlink-manager.log`，方便排查。

## 注意事项

- 不要把链接放在 **OneDrive、坚果云、百度网盘** 等同步目录，同步盘可能不保留软链接。
- 不要把链接放在**网络共享或映射网络驱动器**上，资源管理器对远程重解析点支持很差。
- 链接和目标都放在**本地 NTFS 磁盘**上最稳。
- `symlinks.json` 只是记录，不是链接本体；在资源管理器里手动删了链接，工具会显示「链接不存在」，可选中后删除记录。
- 如果只需要文件夹链接又不想用管理员，优先用 **Junction**。

## 自检

不打开界面，验证创建/删除逻辑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\SymlinkManager.ps1 -SelfTest
```

全部显示 `PASS` 即正常。

## 常见问题：双击链接打不开

1. 选中异常行，看「状态」列和鼠标提示。
2. 确认链接类型：`cmd /c dir /AL "链接所在文件夹"`，目录链接应显示 `<SYMLINKD>` 或 `<JUNCTION>`。
3. 目标失效就删掉链接重建；源被移动/删除/盘未挂载都会导致失效。
4. 确认链接不在同步盘或网络共享上。
5. 文件符号链接双击会用默认程序打开文件，不会打开文件夹——这是正常的。
